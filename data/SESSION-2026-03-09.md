# Session Summary — 2026-03-09

## What Was Built

### OpenSky Network Route Collector (`opensky-collector.py`)
- Python script to query OpenSky `/flights/departure` API and build route data from observed ADS-B traffic
- OAuth2 client credentials flow (token endpoint: `auth.opensky-network.org`)
- Incremental collection: saves progress after each airport, stops gracefully on rate limits
- 23-hour query windows × 3 per airport to stay within partition limits
- Deployed to `10.0.0.128:/usr/local/bin/opensky-collector.py`
- Cron: every 4 hours (`0 */4 * * *`)
- Currently rate-limited (4,000 credits/day budget); will resume collecting on next credit reset

### airportinformation.com Route Scraper (`airportinfo-scraper.py`)
- Scrapes `airportinformation.com/{IATA}/destinations` for nonstop route data
- Extracts destination IATA codes from embedded JSON in `<interactive-map>` component
- Polite 1-1.5s delay between requests

### Where Go U Frontend Updates (index.html)

**Data source toggle** — Radio buttons to switch between:
- "Current (airportinfo)" — scraped nonstop route data (default)
- "OpenFlights (2014)" — legacy static data with airline/stops/equipment info

**Scope filter** — Radio buttons: All / Local / Domestic / International
- Defaults to Domestic
- Filters both the route table and map lines/dots

**Scope column** — Colour-coded sortable column:
- Regional (green) — same state/province
- Domestic (blue) — same country, different region
- International (yellow) — different country

**Colour-coded map** — Route lines and destination dots coloured by scope:
- Green = Regional
- Blue = Domestic
- Red = International

**Map popups with flight search links** — Click any destination dot to see:
- Airport info (name, city, country)
- Airlines serving the route (OpenFlights source only)
- Direct links to: Google Flights, Skyscanner, Kayak, Trip.com, Qunar, Flight Centre

**World map on load** — Map initialises with a world view (zoom 2) instead of blank blue square

**Adaptive table columns** — airportinfo source shows From/To/Distance/Country/Scope; OpenFlights source adds Airline/Stops/Equipment/Note columns
